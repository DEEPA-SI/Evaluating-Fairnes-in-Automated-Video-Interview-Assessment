# Reproducing the public research package

## One default workflow

Use Python 3.11 and the pinned CPU environment in `requirements.lock`. After the
installation commands in the main README, run:

```bash
make all
make test
make lint
```

`make all` checks the publication inventory, then recalculates the public reporting
tables and figures from the included aggregate evidence. It requires neither media
nor embeddings, model downloads, private credentials or a TeX installation.

The default output is `build/reproduction/`. A completed directory is not overwritten:

```bash
make reproduce OUTPUT_DIR=build/reproduction_02
```

The direct, cross-platform command is:

```bash
python -m src.publication --output-dir build/reproduction
```

## What is calculated

| Output | Contents |
|---|---|
| `complete_grid.csv` | All 45 configurations: 15 MIT alpha-1, 15 MIT alpha-1000 and 15 AVI configurations |
| `matched_contrasts.csv` | 112 primary-strength contrast rows, retaining the available phases, axes, units, directions and interval endpoints |
| `contribution_overview.md` | Reader-facing summaries computed from the included evidence |
| `source_receipt.json` | Exact identities of the aggregate inputs and the reporting scope |
| `baseline_quality.svg` and `.png` | MIT predictive-reference comparison, with original-scale error and pooled rank correlation |
| `lambda_tradeoffs.svg` and `.png` | Complete strength responses in predictive error, proxy distance and audited gender distance |
| `primary_gender_gains.svg` and `.png` | Primary matched gender-disparity estimates and their recorded intervals |

The source JSONs retain unrounded values. Rating-scale conversion is applied to those
values, not to displayed rounded numbers: MIT errors are multiplied by six and AVI
errors by four. Score W1 remains on the normalised scale. Positive disparity gains
mean control minus penalty; predictive changes use the explicitly recorded direction.
Small interval endpoints retain their signs.

The included example under `results/reproduction/` is generated by this same command.
The test suite checks deterministic outputs, complete grids, numerical gradients,
Ridge equivalence, group weighting, supported-category handling and interval signs.

## Reporting replay versus experimental reproduction

The public replay recomputes reporting transformations. It does not refit models or
recalculate bootstrap intervals from the aggregate JSONs. The published intervals
describe participant resampling conditional on the fitted models; the complete grids
are exploratory and were not selected using the audit to find a favourable setting.

Source-dependent implementations are included for researchers holding the original
inputs described in [the data guide](../data/README.md). They write fresh output
directories and retain prediction locks before separate annotation joins.
Keep those inputs and participant-level fitted artifacts outside the public release
checkout, and pass their locations explicitly as illustrated below.

### MIT compact fitting and auditing

```bash
python scripts/run_study2_compact.py \
  --feature-dir ../research-inputs/mit-features \
  --stage-a-dir ../research-inputs/stage-a-baselines \
  --output-dir ../research-outputs/mit-alpha1

python scripts/audit_study2_compact.py \
  --run-dir ../research-outputs/mit-alpha1 \
  --annotation-release-dir ../research-inputs/source-annotation-release \
  --output build/mit-alpha1-audit.json --report build/mit-alpha1-audit.md
```

The stronger-reference commands are `scripts/run_mit_strong_ridge.py` and
`scripts/audit_mit_strong_ridge.py`, with the same input arguments and a new output
directory. Their fixed protocol is `configs/mit_strong_ridge_2026_11_19.yaml`;
the existing development-selection aggregate fixes alpha at 1000 in every rotation.
This does not reopen or overwrite the published fits.

### AVI compact fitting and auditing

```bash
python scripts/run_avi_compact.py \
  --release-root ../research-inputs/avi-participant-features \
  --outcomes ../research-inputs/participant-outcomes.json \
  --output-dir ../research-outputs/avi

python scripts/report_avi_compact.py \
  --run-dir ../research-outputs/avi \
  --outcomes ../research-inputs/participant-outcomes.json \
  --audit-attributes ../research-inputs/audit-attributes.json \
  --output build/avi-audit.json --report build/avi-audit.md
```

Explicit outcome/audit arguments avoid any dependence on another checkout's folder
structure. The optional `--intake-release` route resolves the accepted validation
subdirectory through the portable binding in `configs/avi_input_release.json`.

The available published AVI aggregate reports nine converged and six finite-termination
fits, without identifying individual-arm status. Public reporting retains that scope;
it does not infer the primary arm's convergence from the totals.

### Optional neural and extraction components

The original neural scorer, balanced proxy sampler, losses, feature encoders and
training/audit implementations are included under `src/`. The CPU report workflow
does not import their optional neural or media dependencies.

```bash
python -m pip install -e '.[neural]'
# Or, for source-media extraction components:
python -m pip install -e '.[extraction]'
```

Extraction also needs the FFmpeg/FFprobe executables and the source-specific approved
mapping, face selection and model-weight contracts. The original complete environment
is recorded separately in `requirements-experiment.lock`. These are source-dependent
research tools, not additional steps required to use the public results.

## Integrity and attribution

`python -m scripts.publication_manifest --check` verifies the recorded public file
identities. Its inventory covers code, protocols, evidence, documentation and generated
examples, not private inputs. The accompanying source-export record distinguishes
unchanged research code/results from portability-only path adaptations. Numerical
models and published observations are not replaced by illustrative fixtures.
